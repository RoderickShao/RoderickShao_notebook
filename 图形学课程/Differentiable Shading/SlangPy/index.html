    SlangPy

    Nested Types¶

    核心概念：SoA 与 AoS

    术语 全称 内存布局 特点
    AoS Array of Structures（结构体数组） [ {x,y,z}, {x,y,z}, … ] 逻辑清晰，适合 CPU；GPU 访存不连续，性能差
    SoA Structure of Arrays（数组的结构） x[], y[], z[] 独立存储 内存连续、缓存友好，GPU 高效；但逻辑分散

    GPU 编程推荐使用 SoA 存储数据，但 kernel 函数常以 AoS 形式编写逻辑 → 需要自动转换机制。

    SlangPy 的字典机制：连接 SoA 与 AoS¶

    SlangPy 允许通过 Python 字典 传递结构化数据，实现 SOA → AoS 的自动组合：

    src = {
    'x': 1.0,                     # 常量（广播）
    'y': np.random.rand(128,128), # 数组
    'z': 0.0,
    'w': 1.0
}
    • 字典的 key 对应结构体字段名（如 x, y）
    • value 可为：标量、NumPy 数组、GPU buffer、纹理等
    • SlangPy 在 GPU 启动时自动将这些字段组合成目标结构体（如 float4 或自定义 struct）

    优势：

    • 无需在 CPU 端手动拼接大数组（节省内存与计算）
    • 支持混合常量与变量
    • 保持 GPU 代码简洁（使用结构体），同时享受 SOA 性能

    泛型函数中的类型歧义问题¶

    当函数为泛型时（如 copy_vector<N> 或 copy_generic<T>），仅靠字典无法确定具体类型：

    void copy_vector<let N : int>(vector<float, N> src, out vector<float, N> dest)
    • 虽然 dest=tex 可推断目标为 vector<float,4>，
    • 但字典 {'x':..., 'y':...} 缺乏类型标签，可能对应 float4、自定义 struct 或其他类型
    • Slang 为保证类型安全，拒绝猜测，要求显式指定

    解决方案：

    方法 用法 适用场景
    _type 字段 {'_type': 'float4', 'x':..., ...} 推荐！简洁、内联，适用于大多数泛型函数
    .map() 显式映射 func.map(src='float4', dest='float4')(...) 完全泛型（如 T src, T dest），需精确控制类型
    require_function module.require_function('copy_vector<4>') 临时调试，不推荐常规使用

    Type Methods¶

    我们已经看到 SlangPy 能够理解 Slang 中的基本类型和用户自定义类型，并能对全局的 Slang 函数进行自动向量化。除此之外，SlangPy 还可以调用 Slang 类型的方法——无论是可变（mutable）还是不可变（immutable）的方法。这一功能通过以下两个关键类实现：

    • InstanceBuffer：表示一个存储在单个 NDBuffer 中的 Slang 类型实例列表（采用 AoS，即“数组结构”布局）。
    • InstanceList：表示一个以 SOA（Structure of Arrays，即“结构数组”）形式存储的 Slang 类型实例列表，其中不同的字段可以分别存储在不同的缓冲区中。

    例如，我们在 Slang 文件中定义了一个类

    struct Particle
{
    float3 position;
    float3 velocity;

    __init(float3 p, float3 v)
    {
        position = p;
        velocity = v;
    }

    [mutating]
    void update(float dt)
    {
        position += velocity * dt;
    }
};

    那么我在 Python 中应该如何创建这个类呢？

    第一种方法是将其放到 InstanceBuffer 中去管理

    # Create a buffer of particles (.as_struct ensures proper Python typing)
particles = spy.InstanceBuffer(
    struct=module.Particle.as_struct(),
    shape=(10,)
)

# Construct particles with a position of (0, 0, 0) and random velocities
particles.construct(
    p=spy.float3(0),
    v=spy.rand_float(-1, 1, 3)
)

    通过 Update 可以修改当前对象的状态，标记了 [mutating]，SlangPy 知道需要将修改后的数据写回原始 buffer。

    particles.update(0.1)

    第二种方法是将其放到 InstanceLists 中管理

    # Create an InstanceList for particles
particles = spy.InstanceList(
    struct=module.Particle.as_struct(),
    data={
        "position": spy.NDBuffer(device, dtype=module.float3, shape=(10,)),
        "velocity": spy.NDBuffer(device, dtype=module.float3, shape=(10,))
    }
)

    对 construct 和 update 的调用方式保持不变，但 SlangPy 现在会生成一个从独立的位置缓冲区和速度缓冲区中读取并写入的 GPU kernel。

    InstanceList 能够智能区分 Slang 结构体字段与纯 Python 属性，因此支持在 Python 侧进行类继承，允许你安全地扩展自定义属性和方法。

    # Custom type wrapping an InstanceList of particles
class MyParticles(spy.InstanceList):

    def __init__(self, name: str, count: int):
        super().__init__(module.Particle.as_struct())
        self.name = name
        self.position = spy.NDBuffer(device, dtype=module.float3, shape=(count,))
        self.velocity = spy.NDBuffer(device, dtype=module.float3, shape=(count,))

    def print_particles(self):
        print(self.name)
        print(self.position.to_numpy().view(dtype=np.float32).reshape(-1, 3))
        print(self.velocity.to_numpy().view(dtype=np.float32).reshape(-1, 3))

    在 __init__ 中调用父类初始化并传入 Slang 结构体类型，然后添加如 name 这样的 Python-only 属性用于调试，同时显式创建与 Slang 字段同名的 NDBuffer（如 position 和 velocity）以供 GPU 计算使用；继承后，construct() 和 update() 等方法可直接使用，且该实例仍可作为 Particle 数组传递给任何 Slang 函数。

    也就是说上面这个类的对象可以传给以 Particle 数组为参数的 Slang 函数。

    Broadcasting¶

    SlangPy 的广播机制核心在于：将为单个数据单元设计的 Slang 函数，自动扩展为能并行处理批量数据的 GPU kernel。与 NumPy 类似，它通过比较输入参数的“形状”（shape）来决定如何对齐和复制数据，但其能力远超传统数组库——因为它支持任意 Slang 类型，包括向量（如 float3）、结构体、甚至自定义对象。

    广播的关键规则是：首先确定所有参数中的最大维度数，然后逐维检查兼容性——各参数在每一维上的尺寸必须相等，或其中至少一个为 1；尺寸为 1 的维度会被逻辑“拉伸”以匹配其他参数。标量（shape 为 ()）可被广播到任意形状。此外，SlangPy 默认会自动在左侧补 1 来对齐维度（例如将 (3,4) 视为 (1,3,4) 以匹配 (10,3,4)），但可通过 strict_broadcasting=False 关闭此行为，避免意外错误。

    module = spy.Module.load_from_source(..., options={{"strict_broadcasting": False}})

    特别重要的是，SlangPy 的广播不仅看数据的外部形状，还结合函数签名中的参数类型来解析“有效广播维度”。例如，当一个 (10,3) 的数组传给接受 float3 的函数时，最后的 3 被视为 float3 的内部结构，不参与广播，只有前面的 (10,) 作为外部批量维度。因此，add_vectors(float3, float3) 接收两个 float3 时，被视为 shape ()，仅启动一次 kernel；而 add_floats(float, float) 接收相同输入时，会将其拆解为三个标量，启动三次 kernel。

    Mapping¶

    在 SlangPy 中，map 机制提供了一种显式控制函数参数维度与内核（kernel）维度之间映射关系的方法，从而扩展了默认的广播规则，使用户能够更精确地控制向量化行为。

    Warning

    需要注意的是，SlangPy 在描述维度时采用的是机器学习中常见的 NumPy 约定：最左侧的维度（索引为 0）具有最大步长（stride），而最右侧的维度（如索引为 2）具有最小步长。

    一个简单的例子是两个形状为 (10, 3, 4) 的数组相加。默认情况下，SlangPy 会将每个参数的每一维一一对应到内核的相应维度上，即线程 [i, j, k] 处理 a[i, j, k] 和 b[i, j, k]，并写入 result[i, j, k]。

    a = np.random.rand(10, 3, 4)
b = np.random.rand(10, 3, 4)
result = mymodule.add(a, b, _result='numpy')

    这种一对一映射也可以通过 .map((0,1,2), (0,1,2)) 显式指定，或使用命名参数如 .map(a=(0,1,2), b=(0,1,2)) 提高可读性。

    a = np.random.rand(10, 3, 4)
b = np.random.rand(10, 3, 4)
result = mymodule.add.map((0, 1, 2), (0, 1, 2))(a, b, _result='numpy')

    用户通过 map 明确指定如何对齐。例如，若 a 是 (8,8) 而 b 是 (8,)，可以写成 .map(a=(0,1), b=(1,))，这等价于 NumPy 中将 b 广播到第二维。

    a = np.random.rand(8, 8).astype(np.float32)
b = np.random.rand(8).astype(np.float32)

result = mymodule.add.map(a=(0, 1), b=(1,))(a=a, b=b, _result='numpy')

    此外，map 还可用于实现类似外积的操作：将长度为 10 的向量 a 映射到维度 0，长度为 20 的向量 b 映射到维度 1，即可生成形状为 (10,20) 的结果。

    a = np.random.rand(10).astype(np.float32)
b = np.random.rand(20).astype(np.float32)

# Map dimensions:
# - a maps to dimension 0 (size 10)
# - b maps to dimension 1 (size 20)
# Resulting kernel and output shape: (10, 20)
result = mymodule.multiply.map(a=(0,), b=(1,))(a=a, b=b, _result='numpy')

    map 同样支持维度重排，例如通过 .map(val=(1,0)) 实现矩阵转置。

    # Assuming the copy function has the signature float copy(float val)
a = np.random.rand(10, 20).astype(np.float32)

# Swap rows and columns:
result = mymodule.copy.map(val=(1, 0))(val=a, _result='numpy')

    更重要的是，它还能解决泛型函数中的歧义问题。例如，在调用 copy_generic<T> 时，若传入一维数组，可通过 .map(src=(0,), dest=(0,)) 明确告知 SlangPy 每个参数应视为标量（如 float）处理，从而正确生成一维内核。此外，map 还允许直接指定参数类型（如 .map(src='float', dest='float')），进一步简化类型推断。

    # A generic function from the 'nested' section:
void copy_generic<T>(T src, out T dest) {
    dest = src;
}

# Explicitly map dimensions to remove ambiguity:
src = np.random.rand(100).astype(np.float32)
dest = np.zeros_like(src)
result = module.copy_generic.map(src=(0,), dest=(0,))(src=src, dest=dest)

# 指定 src 和 dest 作为一维数组来处理
